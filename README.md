# Veracrypt Portable Container Reader (vc-reader)

I was kinda frustrated that there's no way to open veracrypt files without opening a driver, so I asked Claude to write a tool. It only supports AES now, with NTFS and exFAT. It allows you to view the files inside the Veracrypt container in a nice TUI format.

This is useful for me, it might be useful for you. Good luck.
